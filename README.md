# WitcherBot

A Discord bot inspired by The Witcher universe that lets users embark on monster-hunting quests right from your server. Invoke the `/hunt` command to face off against creatures, earn rewards, and track your achievements—all through simple Discord interactions.

## 📝 Description

WitcherBot brings a taste of Geralt’s monster-hunting adventures to your Discord community. When a user types `/hunt`, the bot generates a hunt scenario—complete with a monster, its stats, and potential loot. Players “battle” the creature (simulated via the bot), and can win experience points, in-game currency, or rare Witcher gear. This lightweight project is designed for quick setup and minimal dependencies.

## 🚀 Installation & Setup

1. **Clone or download this repository**
   ```bash
   git clone https://github.com/yourusername/witcherbot.git
   cd witcherbot

2. **Install dependencies**
    ```npm install```

3. Set up env environment files.

4. Run the bot in development mode
    ```npm run dev```
